# מה לכתוב לקלוד קוד בפתיחת הפרויקט

```
זה NehoRace, משחק מירוץ בעברית שכתוב כולו בקובץ אחד: index.html.
קרא את CLAUDE.md ואת docs/ARCHITECTURE.md לפני שאתה נוגע בקוד.

משימה ראשונה:
1. הרץ את המשחק מקומית ובדוק אותו עם Playwright במסך 390x844 —
   עבור על כל המסכים, ודא שאין שגיאות console, וצלם כל מסך.
2. פצל את הקוד לפי התוכנית ב-docs/ARCHITECTURE.md, מודול אחד בכל פעם,
   ובדוק שהמשחק עובד אחרי כל צעד.
3. אל תשנה שום עיצוב, טקסט או התנהגות בשלב הפיצול.

כללים: עברית בלבד בממשק, בלי ספריות, כל ויזואל מצויר בקוד בקנבס.
```
