# NehoRace

מירוץ נהוראים בפארק. קובץ אחד, בלי שלב בנייה, בלי ספריות.

## הרצה

```bash
python3 -m http.server 8000
```

## מבנה נוכחי

- `index.html` — כל המשחק.
- `CLAUDE.md` — הקשר לקלוד קוד: מסכים, מערכות, כללי עבודה ועיצוב.
- `docs/ARCHITECTURE.md` — מפת הקוד ותוכנית הפיצול לקבצים.
- `docs/FIRST-PROMPT.md` — מה לכתוב לקלוד קוד בהתחלה.
